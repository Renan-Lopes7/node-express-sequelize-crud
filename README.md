## ✨ Funcionalidades

- 📋 Listagem de usuários cadastrados
- ➕ Cadastro de novo usuário
- ✏️ Edição de usuário existente
- 🗑️ Exclusão de usuário
- 📍 Gerenciamento de endereços por usuário

## ▶️ Como executar

```bash
# Clone o repositório
git clone https://github.com/Renan-Lopes7/node-express-sequelize-crud.git

# Entre na pasta
cd node-express-sequelize-crud

# Instale as dependências
npm install

# Configure o banco de dados no arquivo db/conn.js
# e crie o banco MySQL

# Inicie o servidor
node index.js
```

> A aplicação estará disponível em `http://localhost:3000`
